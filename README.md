# RESILIO

### AI-Powered Climate Resilience & Community Planning Platform

RESILIO is an AI-powered decision-support system that helps planners understand climate risks, identify vulnerable communities and infrastructure, and prioritize resilience actions.

## Key Features
- Location-based climate risk assessment
- Flood, landslide, heatwave and cyclone analysis
- Interactive map
- Vulnerable asset identification
- Priority action generation
- What-if rainfall scenario
- RAG-based knowledge support
- IBM Granite for AI-generated resilience recommendations
- Human-in-the-loop decision support

## SDGs
- SDG 11: Sustainable Cities and Communities
- SDG 13: Climate Action

## Technologies
React, Vite, Python, FastAPI, Leaflet, OpenStreetMap, Pandas, NumPy, IBM Granite, RAG, watsonx.ai
